## Задание 3. Подготовка к деплою

**Цель:** Настроить приложение для работы в production-окружении (переменные окружения, запуск через Gunicorn).

1. Дополните `app/config.py`:
   - Добавьте обязательное поле `secret_key`.
   - Добавьте поле `database_url` со значением по умолчанию (SQLite).
   - В `model_config` укажите загрузку переменных из файла `.env`.   
![](./PrtSc/22.jpg)   
2. Создайте файл `.env` (его нельзя коммитить!) и задайте в нём значение `SECRET_KEY`.   
![](./PrtSc/23.jpg)   
3. Убедитесь, что в `app/main.py` заголовок приложения и другие настройки берутся из экземпляра `Settings`.   
![](./PrtSc/24.jpg)   
4. Установите `gunicorn` с помощью `uv add gunicorn`.   
![](./PrtSc/25.jpg)   
5. Создайте скрипт `entrypoint.sh`:
   - Укажите shebang `#!/bin/bash`, флаг `set -e`.
   - Запуск gunicorn на приложении `app.main:app` с следующими параметрами:
     - Количество воркеров берётся из переменной окружения `GUNICORN_WORKERS` (по умолчанию 2).
     - Класс воркера: `uvicorn.workers.UvicornWorker`.
     - Привязка к `0.0.0.0` и порту из переменной `PORT` (по умолчанию 8000).
   - Сделайте файл исполняемым (`chmod +x`).
